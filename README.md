# Repository Intelligence Report

Repository Intelligence Report (RIR) is an open source software intelligence platform for Python projects and GitHub repositories.

## Features

- Code complexity analysis
- Duplicate function detection
- Technical debt scoring
- Refactoring priority recommendations
- Engineering value estimation
- GitHub repository metrics
- Trend analysis
- JSON reporting

## Roadmap

- HTML dashboards
- GitHub Actions integration
- Dependency graphs
- Architecture scoring
- Portfolio valuation
- AI-assisted repository insights
